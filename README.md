# Проектная задача от VK Education
Система поиска и обработки информации на основе RAG. Проект позволяет загружать и обрабатывать контент из различных источников, находить релевантные фрагменты по запросу пользователя и формировать ответ со ссылками на первоисточники.

## Основной функционал (MVP)
- Сбор данных: парсер страниц или постов; сохранение документов в БД с полями title, url, text, дата.
- Чанкинг: разбиение текста на фрагменты, например 300–800 токенов/слов, overlap 50–100.
- Индекс: BM25/TF‑IDF как быстрый вариант без внешних ключей; векторный поиск через FAISS, HNSW или pgvector как усложнение.
- Поиск: endpoint /search?q=... → топ‑N чанков со score и ссылками.
- RAG‑ответ: endpoint /ask?q=... находит топ‑чанки и формирует ответ. Если есть LLM, отправляет контекст и вопрос. Если LLM нет, делает экстрактивный ответ: 3–5 лучших фрагментов и простую суммаризацию.

## Технологии
- Python — основной язык разработки.
- FastAPI — backend и REST API.
- SQLite — хранение документов и метаданных.
- BM25 / TF-IDF — текстовый поиск.
- Embeddings / Vector Search — семантический поиск.
- LLM — генерация ответов на основе найденного контекста.
